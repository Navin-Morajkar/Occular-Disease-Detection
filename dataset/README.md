## Datasets Used:
- [DR 224x224 Gaussian Filtered](https://www.kaggle.com/datasets/sovitrath/diabetic-retinopathy-224x224-2019-data): 
The "DR 224x224 Gaussian Filtered" data-set is one curated set of retinal pics, pre-processed 
using Gaussian filtering techniques will assist identify DR. The original APTOS 2019 dataset 
served as the source of these pictures, specifically resized to a standardized 224x224 pixel 
resolution. This resizing facilitates compatibility with various pre-trained DL models, 
streamlining their incorporation with our applications for analysis and diagnosis. The images 
in each of the five folders that make up the datasets consist of categorized using the train.csv 
file. These pictures show different stages or levels of DR intensity.

- [APTOS 2019 Blindness Detection](https://www.kaggle.com/competitions/aptos2019-blindness-detection)
