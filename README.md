# Ocular Disease Detection Using Deep Learning

## Overview
This project focuses on developing an advanced deep-learning model to detect Diabetic Retinopathy (DR) from retinal fundus images. Leveraging Convolutional Neural Networks (CNN), Hadoop and MapReduce, Vision Transformers, Genetic Algorithms, and Ensemble Techniques, the model aims to enhance diagnostic accuracy, scalability, and reliability. The project demonstrates the potential to automate DR detection, reducing the workload on ophthalmologists and ensuring timely intervention for patients, particularly in underserved regions.

## Features
- **Deep Learning Techniques Implemented**: CNNs, Vision Transformers, Genetic Algorithms
- **Ensemble Learning**: Implements ensemble techniques such as bagging and boosting to improve model performance.
- **Scalable Data Processing**: Integrates Hadoop and MapReduce for efficient and scalable data processing.
- **Data Augmentation & Transfer Learning**: Enhances model robustness and generalization.

## Technologies & Libraries
- **Programming Language**: Python
- **Deep Learning Frameworks**: TensorFlow, Keras, PyTorch
- **Data Processing**: OpenCV, NumPy, Pandas, Scikit-learn
- **Big Data Tools**: Hadoop, MapReduce
- **Optimization Techniques**: Ensemble Techniques
- **Visualization**: Matplotlib, Seaborn
