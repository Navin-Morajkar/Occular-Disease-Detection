# Ocular Disease Detection Using Deep Learning

## Overview
This project focuses on developing an advanced deep learning model to detect Diabetic Retinopathy (DR) from retinal fundus images. Leveraging Convolutional Neural Networks (CNN), Vision Transformers, and Genetic Algorithms, the model aims to enhance diagnostic accuracy, scalability, and reliability. The project demonstrates the potential to automate DR detection, reducing the workload on ophthalmologists and ensuring timely intervention for patients, particularly in underserved regions.

## Features
- **Deep Learning Models**: Utilizes CNNs and Vision Transformers for feature extraction and classification.
- **Ensemble Learning**: Implements ensemble techniques such as bagging and boosting to improve model performance.
- **Hyperparameter Optimization**: Uses Genetic Algorithms for optimizing model parameters.
- **Scalable Data Processing**: Integrates Hadoop and MapReduce for efficient and scalable data processing.
